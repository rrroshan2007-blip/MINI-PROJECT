Prompt 1 — Canvas foundation

Create a C program that implements a 2D character grid canvas of size 25x60. Initialize it with '_' and print it with row and column indices.

Prompt 2 — Plot + display system

Add a function plot(x,y) to safely mark a character '*' on a 2D canvas array, and modify the display function to render the grid properly.

Prompt 3 — Bresenham line algorithm

Implement Bresenham’s line drawing algorithm in C using integer arithmetic to draw a line on the 2D character canvas.

Prompt 4 — Shape abstraction

Define a struct in C to store graphical objects with type (line, rectangle, triangle, circle), coordinates, radius, and active flag. Store multiple objects in an array.

Prompt 5 — Shape rendering system

Write a function redrawAll() that clears the canvas and redraws all active objects from the object array using their respective drawing functions.

Prompt 6 — Rectangle and triangle

Implement rectangle and triangle drawing functions using the existing line drawing function.

 Prompt 7 — Midpoint circle algorithm

Implement midpoint circle drawing algorithm in C and integrate it into the shape rendering system.

Prompt 8 — Add object system

Create a menu-driven function to add shapes (line, rectangle, triangle, circle) into an object array using user input.

Prompt 9 — Modify and delete system

Add functionality to delete and modify existing shapes by ID and automatically redraw the canvas after every change.

 Prompt 10 — Final integration

Combine all features into a single menu-driven C program that supports adding, deleting, modifying, listing objects, and continuously redrawing a 2D ASCII graphics canvas.
